App Checklist

Green check = fully placed; amber = partially placed if you're tracking duplicates; red X = not placed yet. Click a non-green row to drop one onto the current page. Removing a row also removes that app from the phone.

How this works

Long-press any app/folder/widget to enter edit mode (like a real long-press on iOS). While editing, drag anything to any empty cell — a preview shows exactly where it'll land, and dropping near the edge of another icon shifts everything along to make room. Tap empty space (or "Done") to stop editing.
